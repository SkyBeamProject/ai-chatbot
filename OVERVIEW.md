# Overview

An open-source AI chatbot template built on Next.js 14 App Router with React Server Components, Server Actions, and the Vercel AI SDK for streaming. It ships with OpenAI `gpt-3.5-turbo` by default (swappable to Anthropic, Cohere, Hugging Face, or LangChain providers), shadcn/ui + Tailwind + Radix for styling, NextAuth.js for auth, and Vercel KV for chat history, rate limiting, and session storage.
